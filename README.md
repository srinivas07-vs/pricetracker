# 🛒 Price Tracker Website

A Flask-based web application that tracks product prices and sends email alerts when the price drops.

## 🚀 Features
- Track product price
- Compare with previous price
- Send email alert when price drops
- Stores price history in JSON
- Web-based interface

## 🛠 Tech Stack
- Python
- Flask
- BeautifulSoup
- GitHub
- HTML/CSS

## 📩 Email Notification
Sends Gmail alert when price decreases.

## 🌐 Deployment
Hosted online using Render.
